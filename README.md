# pd2-mod-collection

PAYDAY 2 (Diesel 3.0 / 64-bit) SuperBLT mods in one place. Each subfolder is a
self-contained mod — copy it to `PAYDAY 2/mods/` to install. Requires SuperBLT
64-bit; on Proton/Linux use `WINEDLLOVERRIDES="wsock32=n,b" %command%`.

| Folder | Mod | What it does |
|---|---|---|
| `SideJobsCompleter` | Side Jobs Completer v1.2 | Button in Options > Mod Options completes + claims all side jobs, trophies and daily |
| `3xFavors` | 3x Favors Pre-Planning v1.0 | Triples the pre-planning favor pool (host must have it) |
| `CombinedPerkDecksToggle` | All Perk Decks Configurable v3.1 | Grants multiple perk decks at once, per-deck toggles in Lua config |
| `NoNegativeAttachmentStats` | No Negative Attachment Stats + Ammo x5 v1.2 | Flips attachment penalties into bonuses; x5 ammo + pickup |
| `Set5AcedNoFrenzy` | Set 5 All Aced No Frenzy + All Weapon Mods v1.1 | Aces Skill Set 5 (no Frenzy); gives all weapon mods x999 |
| `SelectiveDLCUnlocker` | Selective DLC Unlocker v1.2 (third-party) | Per-DLC unlock toggles — only use with DLCs you own |
| `SelectiveModsHider` | Selective Mods Hider v1.1 (third-party) | Chooses which installed mods are shown to other players |

`SideJobsCompleter`, `3xFavors`, `CombinedPerkDecksToggle`,
`NoNegativeAttachmentStats` and `Set5AcedNoFrenzy` are original to this
collection. `SelectiveDLCUnlocker` (SilentSeduction / DiegoBellik) and
`SelectiveModsHider` (DiegoBellik) are third-party mods mirrored here for
backup; see their folders for details.
